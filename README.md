# TK — 태권도장 통합 운영 서비스 (MVP 소개)

친구 도장과 함께 검토하기 위한 **모바일 친화형 기획 소개 사이트**입니다.

## 소개 페이지
- GitHub Pages 활성화 후: **https://cha-ji.github.io/TK/**
- 원본 저장소: https://github.com/Cha-Ji/TK
- 현재 상태: **기획·클릭형 목업** (운영 서비스가 아님)

## 포함된 6개 클릭형 화면
1. **출결** — 수업별 출석 체크와 통계 변화
2. **차량** — 노선 선택 및 승차 확인
3. **승급** — 승급 심사 결과 기록
4. **내부 회계** — 가상 지출 등록 및 차액 계산
5. **학부모 상담** — 사전 작성된 안내 / 인증 필요 / 담당자 이관 시나리오
6. **FAQ** — 검색 가능한 가상 FAQ

기본 운영 범위로 관원·학부모 DB, 반 관리, 수련비·미납, 공지 및 권한 관리도 기획안에 표시됩니다. 친구 도장은 기본 이용료 무료 파일럿을 제안하며, 문자·알림톡 등 외부 사용량 비용은 추후 협의합니다.

## GitHub Pages 활성화
1. [저장소 Settings → Pages](https://github.com/Cha-Ji/TK/settings/pages) 열기
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main**, Folder: **/(root)** 선택
4. **Save**
5. GitHub Pages 배포 완료 후 위 소개 페이지 주소에서 확인

현재 프로젝트는 빌드 도구 없는 정적 HTML/CSS/JS로 구성되어 GitHub Pages에서 그대로 서비스할 수 있습니다.

## 파일
- \`index.html\`: 서비스 소개 및 여섯 개 목업
- \`style.css\`: 데스크톱·모바일 반응형 스타일
- \`app.js\`: 목업 인터랙션 및 피드백 텍스트 복사

## 안전·범위
- **모든 이름·수치·날짜는 가상 예시입니다.** 실제 아이/학부모 정보는 포함하지 않습니다.
- 이 사이트는 로그인, DB, AWS, 결제, 카카오, 푸시, 실제 AI 상담을 연결하지 않습니다.
- 피드백은 브라우저에서 텍스트 **복사만** 하며 서버로 전송되지 않습니다.
- GitHub Pages는 정적 공개 페이지입니다. 실제 운영 DB/개인정보/비밀번호는 업로드하면 안 됩니다.
- 회계 목업은 내부 수입·지출 장부의 예시이며 법정 세무 신고를 대체하지 않습니다.
- 추후 AWS 서버와 연동할 때 도장별 데이터 격리, 사용자 권한, 개인정보 동의·보관·삭제·감사 기록을 설계해야 합니다.

## 기획 상태
- MVP 범위: 여섯 모듈 및 공통 관원/권한/수납 데이터
- 1차 구현 순서: 관원 DB·출결·수납·내부 회계 → 차량·승급 → FAQ·상담·알림
- 추후 검토: 실시간 차량 GPS, 자동 결제, 세무신고 연계, 고급 분석, 앱스토어 출시
