FAQ 예시
수업 시간은 어떻게 확인하나요?
도장이 등록한 반별 시간표에서 확인할 수 있도록 계획합니다. 이 목업에는 실제 도장 수업 시간이 입력되어 있지 않습니다.
첫 수업 때 준비할 것은 무엇인가요?
예시 안내: 활동하기 편한 복장과 개인 물통을 준비해 주세요. 실제 안내 내용은 관장님이 직접 등록할 수 있습니다.
아이가 결석하면 어떻게 하나요?
학부모 앱에서 결석 예정일과 사유를 전달하고, 담당자가 출석부에서 확인하는 흐름을 구상했습니다.
오늘만 차량을 이용하지 않을 수 있나요?
일시 미탑승 신청 → 담당자 확인 → 차량 탑승 명단 반영의 흐름을 계획합니다.
승급 심사는 언제 진행하나요?
도장에서 확정한 심사 일정과 대상 여부를 학부모 화면에 안내하도록 계획합니다.
수련비 납부 내역은 어디서 보나요?
보호자 본인 확인 후 연결된 자녀의 납부 내역을 조회하도록 설계합니다. 다른 관원의 정보는 볼 수 없습니다.
검색 결과가 없어요. 다른 단어로 찾아보세요.
